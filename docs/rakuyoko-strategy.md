# ラクヨコ事業戦略（Claude × ChatGPT × Gemini）

作成日: 2026-09-23 / 状態: v0.5（Claude案＋Gemini調査を統合済み。ChatGPTの反論待ち）

## 0. 前提の裏取り（Gemini調査 2026-09-24 反映）

| 項目 | 内容 | 戦略への影響 |
|---|---|---|
| アフィリエイト | **成果報酬の対象外**（公式ヘルプに記載なし。運営に問い合わせて「対象外」と回答された報告あり）。解禁予定の公式発表もなし | ラクヨコのリンクでは稼げない。確定 |
| 注文金額 | **2,100円以上で送料無料**。1注文あたり2,100〜16,666円まで。同じ商品は10点まで | 「1,000円以下の神アイテム」よりも「2,100円ぴったりで送料無料にするセット」のほうが実用的なネタになる |
| 配送 | 中国の倉庫から発送、5〜10日。日時指定はできない | 「急ぐなら楽天市場」という導線が自然に作れる（後述） |
| 返品 | Rセレクト商品のみ、発送から30日以内ならユーザー都合でも返品可 | Rセレクトを優先して紹介する |
| 決済 | クレジットカードとコンビニ前払いのみ。楽天ペイ・代引き・PayPayは不可。楽天ポイントは100円につき1pt、ポイント払いも可 | 「楽天ポイントが使える」は訴求ポイントになる |
| クーポン | 会員登録で500円OFF（実質は2,100円以上の購入が条件） | 速報型ネタ |
| 画像 | **サイト掲載の写真・文章は無断転載禁止** | **自分で買って撮った写真だけを使う**。検証型が必須になる |
| 競合 | ラクヨコ専門で伸びている発信者は確認できず | 空白地帯。ただし報酬がないから誰もやっていないとも言える |

補足：Geminiの「解禁される可能性は高い」「上限16,666円は関税対策」は推測で、根拠となる公式情報はない。解禁を前提にした計画にはしない。

## 1. 戦略の骨子：「ラクヨコで集め、楽天市場で稼ぐ」

| 層 | 中身 | 収益 |
|---|---|---|
| 集客 | ラクヨコの新着・激安・検証ネタ（旬で、まだ発信者が少ない） | なし（フォロワー・保存・インプレッション） |
| 収益 | 「ラクヨコ vs 楽天市場の同等品」比較、楽天市場の上位互換品やまとめ買い品 | 楽天アフィリエイト（既存のthreads-affiliate-botの導線） |
| 将来 | ラクヨコが成果対象に加わった瞬間に、リンクを差し替えられる状態にしておく | ラクヨコのアフィリエイト |

既存資産：Threads向けの楽天アフィリエイトbot、PR表記付きの紹介ページ（`index.html`、`r/`、`tiktok/`）。これにラクヨコ用の「ネタ枠」を足すだけで始められる。

## 2. 役割分担（3つのAI）

| AI | 担当 | 理由 |
|---|---|---|
| **Gemini** | 最新事実のリサーチ（アフィリエイト対象か、送料・最低注文金額、キャンペーン、競合発信者の数と伸び方）、YouTube Shorts／Googleトレンド | Google検索との連携と鮮度に強い |
| **ChatGPT** | 投稿フックの大量生成、戦略への反論（レッドチーム）、サムネ画像案 | 発散・言い換え・画像生成 |
| **Claude** | 戦略の統合、長文・比較記事、bot／ページのコード実装、PR表記・ガイドラインのチェック | 長文の整理とコード（このリポジトリ） |

## 3. コンテンツ設計

**型（1投稿＝1型）**
1. 比較型：「同じ〇〇、ラクヨコ◯円・届くまで7日 vs 楽天市場◯円・翌日着 → 結論」← 収益の本命
2. 検証型：「ラクヨコで2,100円分買ってみた：届くまでの日数と品質を正直レビュー」← 自分で撮った写真。信頼の源になる
3. セット型：「2,100円ぴったりで送料無料にするラクヨコ神セット」← 保存を稼ぐ。最低注文金額の制約を逆手に取る
4. 速報型：「ラクヨコのクーポン・セール情報」← フォローの理由になる

**収益への橋渡し（決め台詞）**
- 「今すぐ欲しい人／1個だけ欲しい人は楽天市場のこれ」→ 楽天アフィリエイト（最低注文金額も待ち時間もない、という差で自然に誘導できる）
- 「ラクヨコでハズレだったもの → 楽天市場の定番品ならこれ」

**頻度（目安）**：Threads 3〜5本／日（bot＋手動1本）、ショート動画 1本／日（顔出しなし、画像スライド＋読み上げ）。

## 4. 90日ロードマップ

- **Day 0–14（検証）**：2,100円×2〜3回（合計5,000円前後）を実購入し、到着日数・品質・写真を素材にする。4つの型を各5本ずつ投稿し、保存率・クリック率で勝ち型を決める。
- **Day 15–45（仕組み化）**：勝ち型をbotにテンプレ化。ラクヨコの商品→楽天市場の類似品を探す半自動フローを作る（Claudeで実装）。
- **Day 46–90（拡大）**：Threads・TikTok・YouTube Shortsに横展開。ラクヨコが成果対象になったらリンクを差し替える。

**KPI**：フォロワー／週、保存率、リンククリック率、楽天アフィリエイト報酬／週。30日時点で報酬ゼロならテーマを見直す。

## 5. リスクとルール

- **ステマ規制**：すべての投稿とページに [PR] 表記を付ける（既存ページは対応済み）。
- **楽天アフィリエイトのガイドライン**：誤認を招く表現（「最安」「必ず」など）や、成果対象外リンクの使い回しに注意。
- **画像の権利**：ラクヨコの画像・文章は転載禁止。自分で撮った写真だけを使う。楽天市場の画像はアフィリエイトAPI経由のものに限る（今のbotと同じ）。
- **品質リスク**：激安品の粗悪さは炎上の元。「Rセレクト」を優先し、デメリットも正直に書く。
- **価格変動**：投稿日時を明記し、価格は変わる可能性があると添える。
