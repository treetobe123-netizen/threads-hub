# ラクヨコ事業戦略 v1（Claude × ChatGPT × Gemini 統合版）

作成日: 2026-09-23 / 更新: 2026-09-24 / 状態: v1（3つのAIの意見を統合。30日検証の開始待ち）

## 結論（先に）

- **ラクヨコ単体は事業にならない。** アフィリエイトの対象外で、画像も転載できないため（Gemini）。さらに「数百円の商品を探しに来た人に、楽天市場の高い商品を売る」導線は構造的に弱い（ChatGPT）。
- **本業は「楽天市場の用途特化・実測レビュー」にする。** 投稿で欲しくなった商品と、リンク先の商品が一致する導線（ChatGPTの代替案①）。
- **ラクヨコは30日間の検証枠として使う（作業量の2〜3割）。** 話題性で集客できるか、楽天市場に送客できるかを数字で判定する。ダメなら切る。
- **ラクヨコのアフィリエイト解禁は前提にしない。** 解禁されたら、そのときに差し替える。

## 1. 確定している事実（Gemini調査 2026-09-24／Claudeの検索で裏取り）

| 項目 | 内容 |
|---|---|
| 開設 | 2026-08-25、約6万商品、数百円〜 |
| アフィリエイト | 成果対象外（公式一覧に記載なし。運営に問い合わせて「対象外」と回答された報告あり）。報酬ゼロで計画する |
| 注文条件 | 2,100円以上で送料無料。1注文あたり2,100〜16,666円まで。同じ商品は10点まで |
| 配送 | 中国の倉庫から5〜10日。日時指定は不可 |
| 返品 | Rセレクト商品のみ、30日以内ならユーザー都合でも可 |
| 決済 | クレジットカードとコンビニ前払いのみ。楽天ポイントは付与も利用も可 |
| 画像・文章 | 無断転載禁止。自分で撮った写真だけを使う |
| 競合 | ラクヨコ専門で伸びている発信者はいない（報酬がないから、とも言える） |

## 2. 採算の現実（ChatGPTの試算）

- 1件あたりの報酬 ≒ 注文額2,000円 × 料率3% = **約60円**。
- 10万表示 × ページ到達率0.5% × 楽天への送客率20% × 注文率2% × 60円 = **120円**。
- **再生数を伸ばすより、1件あたりの報酬と送客率を上げるほうが先。**
- Claudeからの補足：楽天アフィリエイトは、リンクを踏んでから24時間以内（条件あり）の他の商品の購入も成果になる。お買い物マラソン・スーパーSALEの時期には、1件あたりの報酬が上がりやすい。単価の高いジャンル（例：今のbotが扱っている抱っこ紐などのベビー用品）で実測レビューをするほうが、採算が合いやすい。

## 3. 30日A/B検証

| | A案（ラクヨコが入口） | B案（困りごとが入口） |
|---|---|---|
| 入口 | ラクヨコの実購入レビュー／2,100円セット | 「狭い洗面所の収納」など用途別の悩み |
| 出口 | ラクヨコのリンク（報酬なし）と、楽天市場の比較品【PR】を並べる | 楽天市場の商品【PR】 |
| 本数 | 15投稿程度 | 15投稿程度（時間帯・本数はA案とそろえる） |

**計測**
- 案ごとに別の `r/` リダイレクトページを使い、クリック数をカウントする（アクセス解析の追加が必要。下の実装TODOを参照）。
- 楽天のレポートは導線ごとに分けて見られない可能性がある。そのため**A案とB案で紹介する商品を重ねない**ようにして、商品別の成果で判定する。

**KPIと撤退ライン（今回の判断用の仮説値）**
- 投稿→紹介ページ：0.5%以上が目標。1万表示以上で0.2%未満なら、フックを直す。
- 紹介ページ→楽天市場：20%以上が目標。A案で300訪問以上あって10%未満なら、「ラクヨコから楽天市場への乗り換え」仮説を捨てる。
- 注文率：2%以上が目標。300クリックで注文ゼロなら、その導線を止める。
- **A案の1,000表示あたり報酬がB案の半分未満なら、ラクヨコ中心の運用はやめる。**
- 採算：（承認された報酬 − 購入費 − ツール代）÷ 作業時間。仮の目標は時給1,000円。

## 4. 運用ルール（信用を守る）

- **PR表記**：投稿の見える位置の先頭に【PR】を付ける。紹介ページにも付ける（既存ページは対応済み）。
- **リンクのすり替えをしない**：「ラクヨコの商品を見る」と「楽天市場の比較商品を見る【PR】」を分け、別の商品であることをクリック前に示す。「ラクヨコで十分」という結論も正直に出す。
- **検証型は実際に買ったものだけ**。買っていない商品は「商品ページの仕様比較」と明記し、使い心地を断定しない。
- **botは下書き・予約を中心にする**。楽天は同じ内容や薄い投稿の繰り返しをスパムとして注意喚起している。価格・在庫・リンク先は公開前に人が確認する。
- 誇張表現（最安・必ず・絶対）は使わない。価格には確認日を添える。

## 5. フック（ChatGPT案から抜粋。Claudeが一部修正）

ChatGPT案は規約に沿っていて安全だが、パンチが弱い。数字と具体性を足した版をたたき台にする。
- A：【PR】ラクヨコで2,100円ぴったり買ったら、届くまで8日。中身を全部見せます
- A：【PR】ラクヨコと楽天市場で同じような収納。送料込みの差は◯円、届く日の差は◯日
- A：【PR】ラクヨコで十分だったもの3つ、楽天市場にすればよかったもの1つ
- B：【PR】洗面台下の奥行き30cmに、実際に入った収納はこれだけでした
- B：【PR】抱っこ紐のヒップシート、3年保証付きと保証なしで何が違うか
（ChatGPTの30案の全文はチャットのログにある。検証型と速報型は、実施した日・新情報がある日にだけ使う）
